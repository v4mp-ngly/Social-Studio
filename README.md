# Social Studio — Creative Management Platform

Prototipo funcional desarrollado en HTML, CSS y JavaScript, creado para el portafolio de Nicole García.

## Ejecutar
Abre `index.html` en un navegador moderno. No requiere servidor ni instalación.

## Incluye
- Dashboard con métricas calculadas de las publicaciones registradas
- Calendario editorial con navegación por meses
- Crear, editar, eliminar y filtrar publicaciones
- Gráficas de actividad editorial
- Ajuste del nombre de marca
- Persistencia local en el navegador (`localStorage`)
- Diseño responsive

## Limitaciones
Las cuatro publicaciones iniciales son ejemplos. Las estadísticas no proceden de Instagram, TikTok, Facebook ni LinkedIn. No existe autenticación, backend, sincronización entre dispositivos ni publicación automática. Para producción, conectar Supabase con políticas RLS y, si corresponde, las API oficiales de las plataformas.
